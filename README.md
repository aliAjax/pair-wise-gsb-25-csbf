# hxwl-11 术后复查台

按患者、眼别和复查时刻记录裸眼视力、眼压、角膜瓣状态与症状，每次复查留档一份；复查判定联动药房续药。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 判定规则

- 眼压 ≥ 25mmHg 或角膜瓣移位 → 记录保留并转 24 小时复诊，药房不能续药
- 无异常且批次在有效期内 → 可按剩余药量发放，并登记批次与数量
- 纠正读数 → 保留旧值与纠正原因，判定按当前读数重新得出

## 目录组织（资料、判定、留档、页面分开）

- `src/data/seed.ts` — 资料：患者、药品批次、示例复查
- `src/domain/types.ts` — 资料结构：复查记录、纠正留痕、批次、发放登记
- `src/domain/rules.ts` — 判定：复诊转诊、批次有效性、发放校验、读数纠正
- `src/archive/store.ts` — 留档：localStorage 持久化，每次复查一份，纠正只追加
- `src/App.tsx` — 页面：复查录入、药房发放、复查留档
