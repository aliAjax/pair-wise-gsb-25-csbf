# hxwl-11 眼科验光复查台

验光页扩展为术后复查台：按患者、眼别、复查时刻记录裸眼视力、眼压、瓣移位与症状，药品余量同单上报；判定联动24小时复诊与药房续药。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 分层结构（资料、判定、留档、页面分开组织）

```
src/
  data/      资料 — 类型定义、基础资料（患者/批次/症状）、格式化
  rules/     判定 — 复查判定与续药闸门的纯函数
  archive/   留档 — 复查记录、纠正留痕、转诊单、发放登记与批次库存
  pages/     页面 — 复查录入、药房续药、复查留档、24小时复诊
```

## 业务规则

- 每次复查按患者、眼别、复查时刻留存一份记录，不覆盖。
- 眼压 ≥ 25mmHg 或瓣移位：记录保留并转24小时复诊，药房不能续药。
- 无异常且批次有效（未过期、有剩余）：可按剩余药量发放，登记批次和数量并扣减库存。
- 纠正读数保留旧值、新值和原因，并重新判定；纠正后不再满足转诊条件的，转诊单标记“纠正后解除”。
- 药品快用完与视力、眼压同单上报，续药必须关联该眼别最近一次复查。
